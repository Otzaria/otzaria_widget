# ווידג'ט אוצריא (Otzaria Widget)

ווידג'טים ללוח הווידג'טים של Windows 11 (`Win + W`) עבור אוצריא, ואפליקציית הגדרות קטנה.
לחיצה על פריט בווידג'ט פותחת אותו ישירות באוצריא.

- **פרויקט עצמאי.** אינו חלק רשמי מאוצריא, ולא נעשה בה שום שינוי.
- **קריאה בלבד.** הווידג'ט קורא את הקבצים המקומיים של אוצריא ולעולם אינו כותב או משנה אותם.
- **עובד גם כשאוצריא סגורה.** הנתונים נקראים ישירות מהקבצים, לא מהתוכנה הרצה.
- **שום מידע לא יוצא מהמחשב.** אין שרתים, אין איסוף נתונים, אין חשבון.

## הווידג'טים

שישה ווידג'טים. לכל אחד גדלים (S = קטן, M = בינוני, L = גדול) ואפשרויות התאמה אישית.
את ההתאמה עושים מתפריט ה-`...` של הווידג'ט ← **התאמה אישית של הווידג'ט** (Customize widget), ושומרים בלחיצה על **שמור**.
כל ווידג'ט ניתן להוספה כמה פעמים, ולכל עותק הגדרות משלו.

| ווידג'ט | גדלים | מה מוצג |
|---|---|---|
| **אוצריא · ספרים אחרונים** | S / M / L | S: פריט אחד, "המשך קריאה" (הלשונית הפתוחה באוצריא כרגע) או "קריאה אחרונה". M: הפריט הזה ועוד עד 2 ספרים אחרונים. L: הפריט הזה ועוד עד 6 ספרים, עם דפדוף. לכל ספר מוצג גם המיקום בו (למשל דף או פרק) |
| **אוצריא · סימניות** | M / L | M: 3 סימניות. L: 5 סימניות, עם דפדוף. מוצגים הכותרת שנתת לסימנייה, הספר והמיקום |
| **שמור וזכור** | S / M / L | התקדמות הלימוד בספרים של "שמור וזכור", עם פסי התקדמות ואחוזים. S: ספר אחד. M: 3 ספרים. L: 4 ספרים, עם דפדוף, וטקסט סטטוס לכל ספר |
| **זמני היום** | S / M / L | העיר והתאריך העברי בכותרת. S: הזמן הבא וספירה לאחור אליו. M: הזמן הבא ועוד שלושה אחריו. L: עד 9 זמנים, כשהזמן הבא מודגש והקודמים לו (עד שניים) מעומעמים. כשכל זמני היום עברו מוצגים זמני מחר |
| **לוח עברי** | S / M / L | התאריך העברי והלועזי ויום בשבוע, ומתחתיהם שורות לפי סדר חשיבות: חג, הדלקת נרות והבדלה, פרשת השבוע, ספירת העומר, דף יומי בבלי, דף יומי ירושלמי. S: שורה אחת. M: 3 שורות. L: עד 6 שורות |
| **אוצריא · לוח אישי** | M / L | לוח משולב שמורכב מהחלקים שבחרת: תאריך היום, הזמן הבא, המשך קריאה, שמור וזכור, סימניות. M: עד 3 חלקים, שורה לכל חלק. L: עד 5 חלקים, ובמקום שיש מקום שורה נוספת |

### אפשרויות התאמה אישית לכל ווידג'ט

| ווידג'ט | אפשרויות (כפי שהן מופיעות בכרטיס ההתאמה) |
|---|---|
| ספרים אחרונים | מספר פריטים (0 = אוטומטי לפי הגודל, עד 8) · הצג את המיקום בספר · כלול ספרי PDF · הצג חיפושים אחרונים (שורה אחת ב-M, שתיים ב-L) |
| סימניות | קבוצה (כל הסימניות / ללא קבוצה / אחת מהקבוצות שלך באוצריא) · מספר פריטים (0 = אוטומטי, עד 8) |
| שמור וזכור | הצג: ספרים בתהליך / ספרים שהושלמו / הכל · מספר פריטים (0 = אוטומטי, עד 8) · הצג את כל העמודות (חזרות) בווידג'ט הגדול |
| זמני היום | עיר (ברירת מחדל: לפי הגדרות אוצריא / הגדרות כלליות) · קבוצת זמנים: כמו באוצריא / מותאם אישית · במצב מותאם: רשימה מוכנה ("עיקריים" או "ברירת המחדל של אוצריא"). רשימה מלאה של כל הזמנים נבחרת באפליקציית ההגדרות (חלה על כל הווידג'טים), ויש בכרטיס כפתור **הגדרות מתקדמות** שפותח אותה |
| לוח עברי | הצג דף יומי (בבלי) · הצג דף יומי ירושלמי · הצג ספירת העומר · הצג הדלקת נרות והבדלה |
| לוח אישי | לכל חלק (תאריך, הזמן הבא, המשך קריאה, שמור וזכור, סימניות): מיקום 1-5 (0 = מוסתר) שקובע את הסדר |

הערה: ווידג'ט שמוצג בגודל גדול יותר מראה יותר פרטים; מספר הפריטים שבחרת מוגבל למקסימום של הגודל (S: 2, M: 4, L: 8).

## דרישות

- Windows 11 (לוח הווידג'טים קיים רק בו), 64 סיביות (x64).
- **Windows App Runtime 1.8** (x64). אם חסר:
  ```powershell
  winget install Microsoft.WindowsAppRuntime.1.8
  ```
  ה-.NET עצמו כלול בחבילה, אין צורך להתקין אותו.
- אוצריא מותקנת, או לפחות תיקיית הנתונים שלה קיימת במחשב (ראו [איך נמצאים הנתונים](#איך-נמצאים-הנתונים)). אוצריא עצמה לא חייבת להיות פתוחה.

## התקנה

הפרויקט עדיין אינו מופץ בחנות או כקובץ מוכן להורדה. יש שתי דרכים להתקין, לפי הצורך.
בשתיהן מתקבלת חבילת MSIX בשם `Otzaria.Widget`.

### למפתחים: התקנה לפיתוח (בלי חתימה ובלי מנהל מערכת)

1. הפעילו **מצב מפתח**: הגדרות ← מערכת ← למפתחים ← Developer Mode (פעם אחת; דורש הרשאת מנהל פעם אחת).
2. התקינו את הכלים: .NET 10 SDK ו-Windows SDK (הסקריפטים מצפים לגרסה 10.0.26100 תחת `C:\Program Files (x86)\Windows Kits\10`).
3. מתיקיית השורש של הפרויקט, בפאוורשל:
   ```powershell
   .\packaging\build.ps1 -Register
   ```
   הפקודה בונה את הפרויקט (`dotnet publish`), מרכיבה את תיקיית החבילה ב-`artifacts\layout`, יוצרת `resources.pri` ורושמת את החבילה (`Add-AppxPackage -Register`).
   אפשר גם לבנות בלי לרשום (`.\packaging\build.ps1`) ולרשום אחר כך עם `.\packaging\install-dev.ps1`.
4. כל בנייה חדשה מקבלת מספר גרסה חדש, כך שהרצה חוזרת של `build.ps1 -Register` מעדכנת את החבילה במקום, והווידג'טים שהצמדתם נשמרים.
5. **חשוב:** ההתקנה היא "קבצים רפויים" (loose files), כלומר Windows מצביע על התיקייה `artifacts\layout`. אל תמחקו ואל תזיזו אותה כל עוד החבילה רשומה.
6. להסרה:
   ```powershell
   .\packaging\uninstall.ps1
   ```
   ההסרה מוחקת רק את חבילת הווידג'ט, ואינה נוגעת באוצריא או בנתונים שלה. אם נוצרה תיקייה `%LOCALAPPDATA%\OtzariaWidget` אמיתית (ולא מנותבת לחבילה) היא נשארת, ואפשר למחוק אותה ידנית.

### להפצה: חבילת MSIX חתומה

```powershell
.\packaging\make-msix.ps1
```

הסקריפט מריץ את `build.ps1` ויוצר בתיקייה `artifacts`:

| קובץ | תפקיד |
|---|---|
| `Otzaria.Widget_<גרסה>_x64.msix` | החבילה, חתומה בתעודה עצמית (Subject `CN=OtzariaDev`) |
| `OtzariaDev.cer` | התעודה הציבורית לאמון |
| `install-msix.ps1` | סקריפט ההתקנה לבודקים |
| `dependencies\` | חבילות Windows App Runtime 1.8, למחשבים שאין בהם (אם נמצאו במטמון ה-NuGet) |

להעברה למחשב אחר מעתיקים את ארבעת אלה יחד לתיקייה אחת, ושם מריצים `install-msix.ps1`
(קליק ימני ← Run with PowerShell). הסקריפט מבקש הרשאות מנהל ומפעיל את עצמו מחדש בהרשאות גבוהות.
**מנהל מערכת נחוץ רק בשל התעודה העצמית:** Windows בודק אמון בחבילות MSIX מול `LocalMachine`, ולכן הסקריפט מייבא את התעודה אל `LocalMachine\TrustedPeople`, מתקין את Windows App Runtime אם הוא חסר (אלא אם ציינתם `-SkipDependencies`), ואז מתקין את החבילה.
תעודת חתימת קוד אמיתית, או הפצה דרך Microsoft Store, מבטלות את הצורך בשלב הזה.

פרטים על רישיונות הרכיבים בסעיף [רישיונות](#רישיונות).

## הוספת ווידג'ט ללוח

1. לחצו `Win + W` לפתיחת לוח הווידג'טים.
2. לחצו על **הוסף ווידג'טים** (סימן ה-`+` בלוח).
3. בחרו **ווידג'ט אוצריא** והוסיפו את הווידג'ט הרצוי. אפשר לשנות את הגודל מתפריט ה-`...`.

## אפליקציית ההגדרות

נפתחת מתפריט התחל (**ווידג'ט אוצריא**), או מכפתור **פתח הגדרות** שבכרטיס ווידג'ט שאין לו נתונים. החלון מוצג בעברית (מימין לשמאל) או באנגלית (משמאל לימין): כברירת מחדל לפי שפת התצוגה של Windows, ואפשר לבחור ידנית בעמוד **תצוגה והתנהגות**. כל שינוי נשמר אוטומטית; הווידג'טים מתרעננים מעצמם. תוכן הווידג'טים עצמם נשאר בעברית.

| עמוד | מה יש בו |
|---|---|
| **מצב** | מה זוהה במחשב (תיקיית הנתונים, `user_state.db`, `app_preferences.hive`, `seforim.db`, `otzaria.exe`, האם גרסה ניידת), כמה ספרים אחרונים, סימניות, ספרים ב"שמור וזכור" וחיפושים נמצאו, מצב כל מקור נתונים, ו"פרטי הזיהוי" לאבחון. כפתורים **רענן** ו**פתח את אוצריא**, והסבר איך מוסיפים ווידג'טים |
| **מיקום הנתונים** | ארבעה שדות לעקיפה ידנית: תיקיית הנתונים של אוצריא, תיקיית מסדי הנתונים, קובץ ספריית הספרים (`seforim.db`), והתוכנה (`otzaria.exe`). שדה ריק = זיהוי אוטומטי. כפתורים **עיון…**, **זיהוי אוטומטי** ו**אפס את כל המיקומים לזיהוי אוטומטי**. מוצג גם הנתיב שבו נעשה שימוש בפועל |
| **זמנים ולוח שנה** | **עיר** (כמו באוצריא, או בחירה ידנית מתוך הרשימה עם סינון) · **הזמנים להצגה** (כמו באוצריא, או בחירה ידנית עם חיפוש וכפתורי "בחר הכול", "נקה הכול", "ברירת מחדל") · **פורמט שעה** (כמו באוצריא / 24 שעות / 12 שעות) · **מעבר היום העברי** (כמו באוצריא / שקיעה / צאת הכוכבים / רבנו תם / חצות) · **הצג דף יומי ירושלמי**. בצד תצוגה מקדימה חיה להיום |
| **תצוגה והתנהגות** | **שפת חלון ההגדרות** (אוטומטי לפי שפת Windows / עברית / English; חל מיד) · **פתיחת קישורים** (ראו [פתיחת ספרים](#פתיחת-ספרים-באוצריא)) · **פרטיות**: **הסתר חיפושים מהווידג'טים** (חיפושים אחרונים לא יוצגו באף ווידג'ט) |
| **אודות** | גרסה, הסבר על פרטיות, **פתח את תיקיית הלוגים**, נתיב קובץ ההגדרות, ו**בדוק קישור** (פותח את `otzaria://open/history`) |

## איך נמצאים הנתונים

ברוב המקרים אין צורך להגדיר כלום. הזיהוי נעשה בסדר הזה, והראשון שנמצא מנצח:

1. **תיקיית הנתונים:** עקיפה ידנית (אם הוגדרה) ← `%APPDATA%\otzaria` ← גרסה ניידת: תיקייה `otzaria_data` שנמצאת ליד `otzaria.exe` שלידו קובץ `portable.marker`.
   את ה-`otzaria.exe` של הגרסה הניידת מוצאים לפי ההגדרה הידנית, `otzaria_capabilities.json`, הרישום של Windows ומקומות התקנה מוכרים. אם הזיהוי לא מצליח, ציינו ידנית את `otzaria.exe` או את תיקיית הנתונים בעמוד **מיקום הנתונים**.
2. **`user_state.db`** (ספרים אחרונים, סימניות, לשוניות פתוחות): בתיקיית מסדי הנתונים: עקיפה ידנית ← `key-databases-path` מהעדפות אוצריא ← `<תיקיית נתונים>\databases` ← `databases` ליד תיקיית הספרייה.
3. **`app_preferences.hive`** (עיר, זמנים, שעון, וההתקדמות ב"שמור וזכור"): בתיקיית הנתונים.
4. **`seforim.db`** (שמות הספרים וגודלם): לפי עקיפה ידנית, `otzaria_capabilities.json`, `library_database_path.txt`, נתיב הספרייה שבהעדפות אוצריא, `library_path.txt`, ברירות המחדל `<תיקיית נתונים>\books` ו-`%ProgramData%\otzaria\books`.
5. **`otzaria.exe`** (לפתיחת קישורים): עקיפה ידנית ← `otzaria_capabilities.json` ← הרישום של Windows ← מיקומי התקנה מוכרים.

הכול נקרא במצב קריאה בלבד, גם כשאוצריא פתוחה באותו זמן. בעמוד **מצב** באפליקציית ההגדרות, תחת "פרטי הזיהוי", רואים איך כל נתיב נמצא.

## פתיחת ספרים באוצריא

כל פריט בווידג'ט הוא קישור מסוג `otzaria://open/...` (למשל `otzaria://open/book/<id>?index=<n>`), שפותח את הספר במקום המדויק.
בעמוד **תצוגה והתנהגות** ← **פתיחת קישורים** יש שתי אפשרויות (`LinkMode` בקובץ ההגדרות):

- **פתיחה ישירה מהווידג'ט** (`OpenUrl`, ברירת המחדל והמומלצת): לוח הווידג'טים פותח את הקישור בעצמו. הכי מהיר ויציב, ומתבסס על כך שאוצריא רשומה ב-Windows לפרוטוקול `otzaria://` (קורה בהתקנה רגילה, ובכל הפעלה של גרסה שאינה ניידת).
- **פתיחה דרך שירות הווידג'ט** (`ProviderLaunch`): שירות הווידג'ט מפעיל את `otzaria.exe` בעצמו עם הקישור. עברו לאפשרות הזאת אם הפתיחה הישירה נחסמת או לא עושה כלום, ובמיוחד **בגרסה ניידת של אוצריא** (לשם כך חייב להיות מוגדר נתיב ל-`otzaria.exe`, ראו **מיקום הנתונים**). האפשרות הזאת לא פועלת כשהמסך נעול.

כדי לבדוק שהקישורים עובדים: **אודות** ← **בדוק קישור**.

## פתרון בעיות

**הווידג'ט לא מופיע ברשימת הווידג'טים להוספה.**
לוח הווידג'טים שומר את הרשימה במטמון. התנתקו והתחברו מחדש ל-Windows, או הפעילו מחדש את שירות הווידג'טים / את סייר הקבצים (`explorer`). ודאו שהחבילה רשומה: `Get-AppxPackage Otzaria.Widget`. אם לא, התקינו מחדש, ובדקו ש-Windows App Runtime 1.8 מותקן.

**"לא נמצאו נתוני אוצריא — פתח את ההגדרות".**
הווידג'ט לא איתר את הקבצים של אוצריא. פתחו את אפליקציית ההגדרות ← **מצב** וראו מה זוהה, ואז ב-**מיקום הנתונים** ציינו ידנית את תיקיית הנתונים (בדרך כלל `%APPDATA%\otzaria`; בגרסה ניידת: `otzaria_data` ליד `otzaria.exe`). אם אוצריא מעולם לא הופעלה במחשב הזה, אין עדיין נתונים.

**לחיצה על פריט לא פותחת את אוצריא.**
עברו ל-**פתיחה דרך שירות הווידג'ט** (**תצוגה והתנהגות** ← **פתיחת קישורים**), ודאו ש-`otzaria.exe` מזוהה (עמוד **מצב**), ונסו **אודות** ← **בדוק קישור**. אם המסך נעול, האפשרות השנייה לא תפעל.

**איפה הלוגים?**
הקובץ `provider.log` (ו-`provider.log.old` אחרי סבב) נמצא באחד משני המקומות, לפי מה שהיה קיים במחשב:

- `%LOCALAPPDATA%\OtzariaWidget\`
- `%LOCALAPPDATA%\Packages\Otzaria.Widget_<מזהה>\LocalCache\Local\OtzariaWidget\`

(Windows מנתב את התיקייה לתוך החבילה רק אם היא לא קיימת כבר במקום הרגיל, למשל אחרי הרצה לא ארוזה.) באותה תיקייה גם `settings.json` (ההגדרות) ו-`settings-ui.log` (לוג אפליקציית ההגדרות).
הדרך הקלה: **אודות** ← **פתח את תיקיית הלוגים**. בלוגים אין תוכן אישי.

**באג ידוע בלוח הווידג'טים של Windows:** אחרי הצגת כרטיס ההתאמה האישית, תפריט ה-`...` של הווידג'ט עלול להפסיק להגיב. זו תקלה של לוח הווידג'טים עצמו (מתועדת במיקרוסופט). סגירה ופתיחה מחדש של הלוח (`Win + W`), ואם צריך התנתקות והתחברות מחדש, אמורות לעזור.

## English summary

**Otzaria Widget** is an independent Windows 11 Widgets Board provider (`Win + W`) plus a small settings app (C# / .NET 10, MSIX) for the Otzaria Hebrew library app.
It reads Otzaria's local data read-only (never modifies Otzaria, works while Otzaria is closed, nothing leaves the computer) and offers six widgets:
Recent books, Bookmarks, Shamor Vezachor progress, Zmanim (daily times), Hebrew calendar, and a personal Dashboard. Clicking an item opens it in Otzaria via `otzaria://` links.

- **Requirements:** Windows 11 x64, Windows App Runtime 1.8 (`winget install Microsoft.WindowsAppRuntime.1.8`), Otzaria installed (or its data folder present).
- **Install (developers):** enable Developer Mode, then `.\packaging\build.ps1 -Register` (or `install-dev.ps1`); remove with `.\packaging\uninstall.ps1`.
- **Install (distribution):** `.\packaging\make-msix.ps1` produces a self-signed MSIX; on the target machine run `install-msix.ps1` as administrator (it imports the certificate into `LocalMachine\TrustedPeople`). A real code-signing certificate or the Microsoft Store removes the admin step.
- **Logs:** `provider.log` is under `%LOCALAPPDATA%\OtzariaWidget\` or `%LOCALAPPDATA%\Packages\Otzaria.Widget_<id>\LocalCache\Local\OtzariaWidget\`.
- **Licensing:** Kosher.Zmanim is LGPL-2.1 and linked dynamically (do not switch to single-file/ILMerge/AOT). Some data (cities, zmanim list and labels) is derived from Otzaria's source code. See [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
- **Developers:** see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
